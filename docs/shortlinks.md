# 短链接服务对比与配置

分享行程 / 目的地推荐时，完整内容压缩编码在 URL hash 里，链接较长（数百到数千字符）。「分享短链接」按钮可将长链转换为短链，支持以下三种服务，在 **设置 -> 高级选项 -> 短链接服务** 中切换（选择保存在浏览器本地）。

## 各服务对比

| | 自有 Worker（默认） | TinyURL | is.gd |
|---|---|---|---|
| 前置条件 | 部署演示 Worker 并绑定 KV（见 [deploy-worker.md](deploy-worker.md) 第六节） | 无（免注册免 Key） | 无（免注册免 Key） |
| 大陆直连 | 与演示代理一致 | 实测可达（2026-08 验证） | **实测不可达**（连接超时） |
| 数据流向 | 只经过自己的 Cloudflare | 链接内容发给 TinyURL | 链接内容发给 is.gd |
| 短链有效期 | 永久（除非删除 KV 记录） | 永久 | 永久 |
| 免费额度 | 每天生成 1000 条（KV 写入限额） | 无明确限制 | 无明确限制 |

## 实测要点（2026-08，本机验证）

- **TinyURL**：`api-create.php` 免 Key、返回 CORS 头（回显请求 Origin），浏览器可直连；短链 301 跳转的 `Location` 完整保留 `#hash`，行程分享链接可正常还原
- **is.gd**：`create.php` 在大陆网络直连超时（连接层失败）；海外网络或开代理时可用，程序内保留为选项并做了失败降级

## 切换方法

1. 打开应用右上角「设置」-> 展开「高级选项」->「短链接服务」
2. 选择服务后点「保存」，选择持久保存在浏览器 localStorage

## 失败降级

无论选择哪个服务，生成失败（超时 5 秒 / 网络不通 / 服务报错）都会自动降级为复制长链接，并在按钮反馈中说明（「短链不可用，已复制长链」）。短链接是纯增益功能，任何配置错误都不影响行程生成等其他功能。

## 为什么没有更多选项

- **51qu.cn、缩我等国内免费短链**：没有公开 API（网页表单提交）或无 CORS 头，浏览器无法调用
- **bit.ly、短链精灵等**：需要 API Key，纯前端架构无法安全保存 Key（会暴露在前端代码里）
- **国内云厂商短链服务**：需付费或备案域名，超出个人免费范畴

## 隐私须知

短链接服务会把完整长链接（即全部行程 / 推荐数据）发送给所选服务的服务器。数据本身是准备分享的内容，但如介意经过第三方，选「自有 Worker」--数据只经过你自己的 Cloudflare 账号。
