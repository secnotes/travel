# 悠行 · AI 旅行规划

纯前端的 AI 旅行规划 Web 应用。浏览器直连 OpenAI 兼容大模型 API，
结合本地维护的景点 / 气候 / 消费结构化数据（防幻觉接地），生成可靠的逐日行程。

## 功能

### 行程规划
输入**天数、目的地（省份 / 城市 / 景点）、出发地**，可附加出发日期、预算档位（穷游 / 舒适 / 奢华）、节奏、主题偏好：
- 生成逐日行程卡片（时间轴、门票、交通与住宿建议）
- 地图动线：Leaflet + 高德瓦片，按天着色标记与路线
- 预算估算：基于城市三档消费锚点，分项展示、可整体缩放
- 多轮修改：对话式微调（"第二天太累，减一个景点"）
- 16 天内出行自动拉取 Open-Meteo 天气预报辅助决策
- 行程期间含法定节假日时给出避峰提示

### 目的地发现
只知道出行时间不知道去哪？输入**时间段 + 出发地 + 偏好**，
AI 顾问综合当季气候、季节性景观（花期 / 红叶 / 冰雪）、节假日人流与距离，
推荐 5-8 个目的地并附理由，一键跳转行程规划。

### 导出与分享
- 导出 Markdown 文档
- 打印样式（浏览器"另存为 PDF"）
- 分享链接：行程压缩编码进 URL，**无需后端**，打开即还原

## 快速开始

```bash
npm install
npm run dev
```

打开应用后点击右上角「设置」，选择模型服务商并填入 API Key（推荐
[DeepSeek](https://platform.deepseek.com/api_keys)，或使用智谱 glm-4-flash 免费额度）。
Key 只保存在你的浏览器 localStorage 中，请求由浏览器直连服务商。

### 线上访问地址

- 若仓库部署为**项目页**（仓库自建、用 `<用户名>.github.io/<仓库名>/` 地址），
  访问入口带仓库名子路径，如 `https://secnotes.github.io/travel/`（**注意末尾 `/`**）。
- 若绑定了自定义域名且根域名已被**用户主页仓库**（`<用户名>.github.io`）占用，
  本项目只能走子路径访问，如 `https://secnotes.cn/travel/`——
  根域名 `https://secnotes.cn/` 仍由你的用户主页提供。
  `vite.config.ts` 的 `base: './'` 已用相对路径，子路径下可正常加载资源。

> 必须在仓库 **Settings → Pages → Source** 选 **"GitHub Actions"**（不是 "Deploy from a branch"），
> 否则线上会发布未构建的源码导致白屏（详见部署文档「常见问题」）。

## 架构

```
用户输入 ──> resolver（匹配本地数据集，组装景点/气候/节假日/天气上下文）
        ──> prompts（系统提示词 + 结构化上下文）
        ──> LLM（OpenAI 兼容 /chat/completions，SSE 流式）
        ──> zod 校验（失败自动带着错误重试）
        ──> enrich（回填数据集坐标/门票、补日期）
        ──> 渲染（行程卡片 / 地图 / 预算 / 对话修改）
```

**混合数据策略**：LLM 只能编排本地数据集中给出的景点（填 attractionId），
数据集外的内容必须标记 `verified=false`（UI 显示"待核实"），
从机制上抑制大模型编造景点与价格的幻觉问题。

## 数据格式与扩充

景点 / 城市 / 气候数据位于 `src/data/regions/*.ts`，字段说明见 [data/README.md](data/README.md)。
欢迎按格式补充你熟悉的地区 - 数据集越全，行程越可靠。

## 已知限制

- 纯前端架构：API Key 暴露于浏览器（个人使用场景可接受，公开部署请自担风险或加网关）
- 大交通（机票 / 火车票）价格为 AI 估算，未接实时票价（接口已预留 adapter 扩展位）
- 2027 年节假日调休安排以官方公布为准
- Open-Meteo 免费版仅支持 16 天内的天气预报
